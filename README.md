# Student Study Assistant

A beginner-friendly Python study assistant designed to help students manage their subjects and study tasks.

## Features

- Add and view subjects
- Delete and clear subjects
- Add, view and delete study tasks
- Mark tasks as completed
- Study progress tracking
- High, medium and low priority tasks
- Clear all tasks
- Data is stored using text files
- Simple command-based interaction

## Technologies Used

- Python
- File Handling
- Lists
- Loops
- Conditions
- Exception Handling
- Texts Files
- Command-Line Interface(CLI)

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

add subject
view subjects
add task
view tasks
